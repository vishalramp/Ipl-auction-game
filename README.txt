VRAMP IPL Auction recreation
=============================

This is a standalone front-end recreation inspired by the supplied screenshots.
It includes:
- Dark IPL-auction style home screen
- Team selection
- Create-room screen
- Public/private room UI
- Room/invite/chat screen
- Working auction screen with bid controls
- Small "vramp" watermark in the bottom-right corner

Run:
1. Unzip the folder.
2. Open index.html in a browser.

No build tools or internet connection are required.
This is an unofficial recreation and is not affiliated with IPL, BCCI, or the original site.
